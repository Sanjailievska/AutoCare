# AutoCare — Auto Repair Shop Management Platform

AutoCare — a full-stack repair-shop management platform (React, TypeScript, Supabase). Built the complete workflow from scratch: customer/shop/admin roles with Supabase Auth, a Postgres schema with Row Level Security enforcing per-role data isolation, a multi-step repair-request wizard, a line-item estimate builder with live approval flow, image uploads via Supabase Storage, and real-time in-app notifications driven by database triggers. Deployed live on Netlify with CI from GitHub.
Live: https://autocare4.netlify.app · Code: https://github.com/Sanjailievska/AutoCare
